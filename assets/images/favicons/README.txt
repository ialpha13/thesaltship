# The Saltship Favicon Package

This package includes:
- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- favicon-48x48.png
- Apple Touch Icon: apple-touch-icon.png
- Android Chrome icons: 192x192 and 512x512
- Microsoft tile icons
- site.webmanifest
- browserconfig.xml
- HTML head snippet

Upload the files to your website root directory, then paste the HTML from `html-head-snippet.txt` into the `<head>` section of your website.

A `dark-background-alternative` folder is also included because the original logo is white/very light and can become invisible on light browser backgrounds.
