# The Salt Ship

A PHP-based website built for a local WAMP environment. The project includes static page templates, reusable components, and assets for CSS, JavaScript, and images.

## Project Structure

- `index.php` — main entry point
- `includes/` — shared layout and helper files
- `components/` — reusable UI components
- `pages/` — individual page templates
- `assets/` — CSS, JS, images, and site data

## Setup

1. Place the project folder in your WAMP or local PHP server root.
2. Start Apache and MySQL if required.
3. Open `http://localhost/thesaltship/` in your browser.
